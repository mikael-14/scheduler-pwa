# pwa-scheduler

## Overview
This project is a Vue.js Progressive Web Application (PWA) designed for scheduling tasks. It utilizes Docker for containerization and Vite as the build tool.

## Project Structure
```
pwa-scheduler
├── src
│   ├── main.ts
│   ├── App.vue
├── public
│   ├── img/icons      # app icons (home screen, splash, notifications)
│   └── push-sw.js     # web push handlers, imported by the generated service worker
├── Dockerfile
├── docker-compose.yml
├── package.json
├── vite.config.js     # also the PWA manifest (name, colours, icons) and service worker
└── README.md
```

## Installing on a phone

The manifest and service worker are generated by `vite-plugin-pwa` (see `vite.config.js`).
The app shows an **"Adicionar ao telemóvel"** button on the login page, in the side menu and in
Settings (`src/components/common/InstallButton.vue`, `src/utils/install.ts`):

- Android (Chrome, Edge, Samsung Internet) and desktop Chrome/Edge: opens the browser's install dialog.
- iPhone / iPad: explains Share → "Add to Home Screen" (Safari has no install dialog). Push
  notifications on iPhone only work once the app is added this way.
- Other mobile browsers: explains where the install option is in the browser menu.
- Hidden when the app already runs installed.

Installing needs **HTTPS** (or `localhost`): on a phone, use the real domain or a tunnel, not the
computer's LAN IP over http. To change the logo, replace the PNGs in `public/img/icons` with the
same sizes (the maskable one keeps the logo inside the middle 80%).

## Getting Started

### Prerequisites
- Docker
- Docker Compose

### Installation
1. Clone the repository:
   ```bash
   git clone <repository-url>
   cd pwa-scheduler
   ```

2. Build the Docker image:
   ```bash
   docker-compose build
   ```

3. Start the application:
   ```bash
   docker-compose up
   ```

### Usage
- Access the application at `http://localhost:5173`.
- The application supports offline functionality and can be installed as a PWA.

### SSH

```
docker exec -it pwa-scheduler-web sh
```
